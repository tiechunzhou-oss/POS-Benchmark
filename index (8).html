POS Feature & Pricing Benchmark

Pick a country, then the competitors you want, then the specific packages to line up. Each selected package becomes one column. Rows are split into Package (cost) and Feature (capability), with each feature's sub-items grouped beneath it.

Package vs. Feature. Every column is split into two parts: Package covers cost (TCO for the first year, the recurring subscription fee, and what hardware is included), and Feature covers capability — what each package can actually do.

DISH is always shown first and stays pinned to the left edge even when you scroll right, so it's always there to compare against.

Bundled vs. Modular competitors. Most competitors offer a small number of fixed packages — pick as many as you want to compare. A few (like Square) let you choose hardware and software independently; for those, pick any hardware tier and any software tier, and every combination becomes its own column.

TCO (1st year) for a bundled package is read directly from the sheet. For a modular combination, it's calculated as hardware price + first-year subscription cost, correctly annualized depending on whether the subscription is billed monthly or yearly.

  • Included — part of the package at no extra cost.
  • Included, limited — included, but only a basic version.
  • Not available — this competitor doesn't offer it.
  • Add-on — available for an extra fee.
  • Supported — confirmed available, but we don't yet know if it's included at no cost or an add-on.
  • n/a — not yet researched.
